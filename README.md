# Глазов Е.А. — выездной автоэлектрик, Гомель

Одностраничный сайт для выездного автоэлектрика и автомеханика: круглосуточная помощь
на дороге, отогрев в мороз, диагностика и ремонт на месте, аргоновая сварка.
Гомель и Гомельская область.

**Живой сайт:** https://romjjjke.github.io/glazov-avto/

## Что внутри

1. Герой: телефон, режим 24/7, зона выезда, что берётся в машину.
2. Вольтметр — пин-сцена на 1,75 экрана: 8,4 → 12,6 → 14,4 В, стрелка, лампы, три акта одного выезда.
3. Шесть задач на выезде с границей «что на месте не делается».
4. «Первые 10 минут, пока еду» — протокол для клиента на светлой полосе.
5. Мороз: отогрев вместо эвакуации.
6. Как складывается цена: без выдуманного прайса, с честным объяснением.
7. Вызов: телефон, WhatsApp, форма с адресом, машиной и описанием.

## Стек

React 18 + Vite + TypeScript. GSAP + ScrollTrigger (только пин-сцена), Lenis (плавный скролл),
появление блоков на IntersectionObserver. Шрифты самохостингом: Fira Sans Condensed + Source Sans 3,
79 KB на 8 файлов, метрические фолбэки с `size-adjust`.

## Замеры

Lighthouse mobile (GitHub Pages): performance 100, accessibility 100, best practices 100, SEO 100.
LCP 1,8–1,9 с, CLS 0, TBT 0. Ширины 320–1680 без горизонтального скролла.

## Локально

```bash
npm ci

npm run build   # продакшн-сборка в dist
```

Деплой: GitHub Actions (`.github/workflows/deploy.yml`), ветка `main`, артефакт `dist`, Pages workflow.

## Ограничения

Прайса у заказчика нет, поэтому цены на сайте не выдуманы: вместо цифр — состав суммы и правило
«называю до выезда». Фотографий реальных выездов нет: вся графика нарисована. Отзывов нет.
